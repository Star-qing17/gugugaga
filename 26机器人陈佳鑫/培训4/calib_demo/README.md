# 培训4：相机内参标定与畸变矫正

使用 OpenCV 实现张正友标定法（张氏标定），从一组棋盘格标定图中求解相机内参矩阵 `K` 与畸变系数 `D`，
并用 `cv::undistort` 对图像做畸变矫正。

## 标定板参数

- 棋盘格：11 × 8 个方格 → 内角点 **10 × 7**
- 方格边长：**15 mm**

## 编译

```bash
mkdir -p build && cd build
cmake ..
make -j4
```

## 运行

```bash
./build/calib_demo <标定图目录> [输出目录] [最多使用的有效图片数]
```

示例：

```bash
./build/calib_demo ~/calib_photos .
./build/calib_demo ~/calib_photos . 90
```

- 第 1 个参数：标定图所在目录（必填，目录内为 `*.jpg`）
- 第 2 个参数：结果输出目录，默认当前目录
- 第 3 个参数：最多使用的有效图片数，默认 90

标定原图共 113 张，程序按文件名顺序扫描，凑够指定数量的有效图（成功检出角点）后即停止。

## 输出

终端打印：

```
used images: 90 / 113
reprojection rms = 1.28139 px
camera matrix K =
[634.8045191329343, 0, 321.8020203325622;
 0, 638.9217395423013, 227.3139550183815;
 0, 0, 1]
distortion D = [-0.4249430689019879;
 0.2055029400565848;
 -0.0009480601117317194;
 -0.001416134610023823;
 -0.02372775410528711]
saved: ./undistort_result.jpg
```

其中 `D` 的顺序为 `[k1, k2, p1, p2, k3]`。

结果文件 `undistort_result.jpg` 为原图与矫正结果的并排对比（左：矫正前，右：矫正后）。

## 结果

| 项目 | 值 |
| --- | --- |
| 有效图片 | 90 / 113 |
| 重投影误差 (rms) | 1.28139 px |
| fx, fy | 634.8045, 638.9217 |
| cx, cy | 321.8020, 227.3140 |
| k1, k2 | -0.42494, 0.20550 |
| p1, p2 | -0.00095, -0.00142 |
| k3 | -0.02373 |

k1 为负、k2 为正，符合该镜头明显的桶形畸变特征；矫正后图像边缘拉直。
